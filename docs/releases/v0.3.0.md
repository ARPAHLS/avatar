# AVATAR v0.3.0

**Released:** 2026-08-04  
**Tag:** [v0.3.0](https://github.com/ARPAHLS/avatar/releases/tag/v0.3.0)

Open-source **VRM desktop companion** — transparent always-on-top overlay with VRMA motion, real-time lip sync, and optional **VRoid Hub** account connection for link-only characters.

## Download

- **Windows (x64):** [AVATAR-Setup-0.3.0.exe](https://github.com/ARPAHLS/avatar/releases/download/v0.3.0/AVATAR-Setup-0.3.0.exe)

Drag the glass bar to move; use Gear for Appearance, Voice, Camera, Animations, and Settings.

## Install options

1. **Windows installer** (easiest) — no Node.js  
2. From source: `cd avatar && npm install && npm run desktop`  
3. Web / contributors: `npm run dev` → http://localhost:5173  

## Highlights

- **VRoid Hub (optional):** bring-your-own OAuth app → connect in Settings → pick characters under Appearance → Avatars (session-only Hub VRMs)
- VRM 1.0 models face the camera correctly (settings version 2 migration)
- Electron overlay (pin / windowed) with ×0.5 / ×1 / ×2 scale and a 3×3 snap pad
- Device-output lip sync on desktop (plus window / mic / file)
- Preferences saved to `config.yaml`
- Unversioned **AVATAR Installer** branding art

## Requirements

- Windows 10/11 x64
- No Node.js required for the installed app

# AVATAR v0.2.0

**Released:** 2026-08-01  
**Tag:** [v0.2.0](https://github.com/ARPAHLS/avatar/releases/tag/v0.2.0)

Open-source **VRM desktop companion** — transparent always-on-top overlay with VRMA motion and real-time lip sync (system audio, window, mic, or file).

## Download

- **Windows (x64):** [AVATAR-Setup-0.2.0.exe](https://github.com/ARPAHLS/avatar/releases/download/v0.2.0/AVATAR-Setup-0.2.0.exe)

Drag the glass bar to move; use Gear for Appearance, Voice, Camera, Animations, and Settings.

## Install options

1. **Windows installer** (easiest) — no Node.js  
2. From source: `cd avatar-demo && npm install && npm run desktop`  
3. Web / contributors: `npm run dev` → http://localhost:5173  

## Highlights

- Electron overlay (pin / windowed) with ×0.5 / ×1 / ×2 scale and a 3×3 snap pad
- Avatars & skins, built-in environments, color fade (Custom is local/dev only)
- Device-output lip sync on desktop (plus window / mic / file)
- Preferences saved to `config.yaml`
- Installer EULA + ARPA branding

## Requirements

- Windows 10/11 x64
- No Node.js required for the installed app

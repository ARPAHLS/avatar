# AVATAR v0.5.0

**Released:** 2026-08-06  
**Tag:** [v0.5.0](https://github.com/ARPAHLS/avatar/releases/tag/v0.5.0)

Open-source **VRM desktop companion** — transparent always-on-top overlay with VRMA motion, real-time lip sync, faster Appearance avatar thumbnails, **View on VRoid Hub** from the hearted-model gate, and **Settings → Directories** for your own avatar and environment folders.

## Download

- **Windows (x64):** [AVATAR-Setup-0.5.0.exe](https://github.com/ARPAHLS/avatar/releases/download/v0.5.0/AVATAR-Setup-0.5.0.exe)

Drag the glass bar to move; use Gear for Appearance, Voice, Camera, Animations, and Settings.

## Install options

1. **Windows installer** (easiest) — no Node.js  
2. From source: `cd avatar-demo && npm install && npm run desktop`  
3. Web / contributors: `npm run dev` → http://localhost:5173  

## Highlights

- **Static avatar thumbnails** in Appearance — bundled PNGs + custom-folder cache; no multi-second stall opening the drawer (#10, #20)
- **View on VRoid Hub** on hearted-model conditions-of-use gate (#18, #19)
- Docs: avatars guide renamed to [`docs/avatars.md`](../avatars.md); issue-reporting checklist in CONTRIBUTING (#25, #27, #30, #31)
- Fixes: VRM GPU dispose on avatar swap; `dev:desktop` localhost / `--strictPort` (#20)

## Requirements

- Windows 10/11 x64
- No Node.js required for the installed app

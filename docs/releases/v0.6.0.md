# AVATAR v0.6.0

**Released:** 2026-08-07  
**Tag:** [v0.6.0](https://github.com/ARPAHLS/avatar/releases/tag/v0.6.0)

Open-source **VRM desktop companion** — transparent always-on-top overlay with VRMA motion and real-time lip sync, plus **CI**, broader **ESLint**, desktop companion **docs GIFs**, package directory rename to `avatar/`, and contributor fixes for `dev:desktop` teardown and custom environment blob URLs.

## Download

- **Windows (x64):** [AVATAR-Setup-0.6.0.exe](https://github.com/ARPAHLS/avatar/releases/download/v0.6.0/AVATAR-Setup-0.6.0.exe)

Drag the glass bar to move; use Gear for Appearance, Voice, Camera, Animations, and Settings.

## Install options

1. **Windows installer** (easiest) — no Node.js  
2. From source: `cd avatar && npm install && npm run desktop`  
3. Web / contributors: `npm run dev` → http://localhost:5173  

## Highlights

- **GitHub Actions CI** — lint, Electron unit tests, and production Vite build on every PR and `main` (#4, #35)
- **ESLint** covers Electron (`electron/**/*.cjs`) and build scripts; `npm run lint` is `--max-warnings=0` (#34)
- Package directory renamed `avatar-demo/` → `avatar/`; companion GIFs in README and guides (#3, #32)
- Fixes: `dev:desktop` tears down Vite when the window closes (#37, #38); custom env library blob URLs revoked only after replacement (#39, #40)
- Citation: Heng-Cheng Hsu (許恒誠) added to [`CITATION.cff`](../../CITATION.cff) (#41)

## Requirements

- Windows 10/11 x64
- No Node.js required for the installed app

# AVATAR v0.8.0

**Released:** 2026-09-06  
**Tag:** [v0.8.0](https://github.com/ARPAHLS/avatar/releases/tag/v0.8.0)

Open-source **VRM desktop companion** — transparent always-on-top overlay with VRMA motion and real-time lip sync, plus a **local agent bus**, **Streamable HTTP MCP**, adjustable **Voice lip-sync** controls, a **reactive live dot**, **SECURITY.md**, and a machine-readable **asset license manifest**.

## Download

- **Windows (x64):** [AVATAR-Setup-0.8.0.exe](https://github.com/ARPAHLS/avatar/releases/download/v0.8.0/AVATAR-Setup-0.8.0.exe)

Drag the glass bar to move; use Gear for Appearance, Voice, Camera, Animations, and Settings. Enable **Agents** when you want scripts or an editor MCP client to drive the stage.

## Install options

1. **Windows installer** (easiest) — no Node.js  
2. From source: `cd avatar && npm install && npm run desktop`  
3. Web / contributors: `npm run dev` → http://localhost:5173  

## Highlights

- **Local agent bus** — Settings → Agents: opt-in loopback API (`127.0.0.1:47903`) for `animation.play`, avatar/environment/audio commands (#6, #55)
- **MCP on the bus** — Streamable HTTP at `/mcp`; Copy MCP URL + token; `play_animation` defaults to once (#61, #63)
- **Adjustable lip-sync** — Voice → Sensitivity and Mouth limit, persisted in `config.yaml` (#67)
- **Reactive live dot** — waiting / live / error states with amplitude-driven pulse (#42, #54)
- **SECURITY.md** — private vulnerability reporting and scope notes (#26, #64)
- **Asset license manifest** — machine-readable inventory + CI path validation (#11, #62)
- Voice capture status / privacy copy improvements (#12)

## Requirements

- Windows 10/11 x64
- No Node.js required for the installed app

## Notes

- The installer is currently **unsigned** (SmartScreen may warn — “More info” → Run anyway).
- Sample VRM/VRMA assets retain their upstream licenses (VRoid / pixiv). See [Assets & credits](../assets-and-credits.md).
- The agent bus and MCP endpoint are **off by default**, loopback-only; keep **Require token** on unless you accept that any local process can drive the stage.
- Clients that send an `Origin` header are refused (CLI/editor MCP clients typically do not; webview-based desktop MCP clients are not supported in this version).
- Hub characters stay in memory for the session only (not written to disk / `config.yaml`).

# AVATAR v0.7.0

**Released:** 2026-08-16  
**Tag:** [v0.7.0](https://github.com/ARPAHLS/avatar/releases/tag/v0.7.0)

Open-source **VRM desktop companion** — transparent always-on-top overlay with VRMA motion and real-time lip sync, plus **Motion Deck** hotkeys, a validated **stage command layer**, **custom `.vrma` folders**, leaner environment pickers, and production builds that keep trial `custom/` media out of the installer.

## Download

- **Windows (x64):** [AVATAR-Setup-0.7.0.exe](https://github.com/ARPAHLS/avatar/releases/download/v0.7.0/AVATAR-Setup-0.7.0.exe)

Drag the glass bar to move; use Gear for Appearance, Voice, Camera, Animations, and Settings. Bind one-shot gestures under Settings → **Animation hotkeys**.

## Install options

1. **Windows installer** (easiest) — no Node.js  
2. From source: `cd avatar && npm install && npm run desktop`  
3. Web / contributors: `npm run dev` → http://localhost:5173  

## Highlights

- **Motion Deck** — Settings → Animation hotkeys: shortlist clips, bind chords, fire once without changing the Animations selection (#24, #51)
- **Stage command layer** — validated `animation.play` / `avatar.set` / `environment.set` / `audio.source`, including `mode: once` for overlays; groundwork for the agent bus and keyword triggers (#6, #50, #51)
- **Custom animations folder** — Settings → Directories → Animations points at your `.vrma` pack (#23, #45)
- **Environment picker posters** + lazy custom-folder reads — GIFs load only for the stage, not every thumb (#22, #49)
- Production builds omit local `custom/` environment trial media by default (#13, #44)
- Maintainer [release checklist](../development/release-checklist.md) (#28, #47)
- Fix: re-selecting the avatar already on stage no longer hides the companion (#6, #50)

## Requirements

- Windows 10/11 x64
- No Node.js required for the installed app

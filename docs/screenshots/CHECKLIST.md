# Screenshot checklist

Capture these for the docs. Drop files under `docs/screenshots/` using the **Suggested filename**.

**Status:** most shots are in and linked from README / guides. **H (animations)** skipped for now (possible GIFs later). Missing optional: I3–I5 snap full-desktops, I7 reset close-up, J1 banner, J3 browser.

**Conventions**

| Kind | Meaning | Docs display |
| :--- | :--- | :--- |
| **Window** | Cropped Electron companion only | Fixed height (esp. in multi-image rows) |
| **Full** | Whole desktop / monitor | Full width |
| **Drawer** | Gear drawer open | Fixed height |

Prefer **Avatar 1** as the “hero” character unless a shot is avatar-specific. Use **Default** animation unless noted.

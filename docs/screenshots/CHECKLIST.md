# Screenshot checklist

Capture these for the docs. Drop files under `docs/screenshots/` using the **Suggested filename** (or keep your names and send links — we’ll wire them into README and docs).

**Conventions**

| Kind | Meaning |
| :--- | :--- |
| **Window** | Cropped Electron companion only (transparent edges OK) |
| **Full** | Whole desktop / monitor with companion over a real app |
| **Drawer** | Gear drawer open, companion window framed |

Prefer **Avatar 1** as the “hero” character unless a shot is avatar-specific. Use **Default** animation unless noted. Restart Electron after UI changes before shooting.

## Capture tips

1. Hide personal paths in shots if you prefer (`config.yaml` path can be cropped or blurred).
2. For **Full** shots, use a clean desktop wallpaper or a recognizable dark/light app.
3. Keep the companion **×1** unless the shot is specifically about scale.
4. After drag-moving the window, confirm snap highlight clears before shooting “idle” settings.
5. When ready, drop files in `docs/screenshots/` (create the folder) and paste paths/links here — we’ll embed them in README and the guides.

**Priority if time is short:** A1, A2, A3–A5, C1, C2, D1, D3, D6–D9, E1, E2, F1, F5, G1, H1, I1, I2, B3–B6, J1.
